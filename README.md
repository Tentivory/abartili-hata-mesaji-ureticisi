# Abartılı Hata Mesajı Üreticisi

## Giriş
Bu repository, yazılım dünyasının en ciddi sorununa çözüm getirmek için tasarlanmıştır: **Sıkıcı hata mesajları.**

Artık "SyntaxError: unexpected token" gibi düz, duygusuz mesajlarla yetinmek zorunda değilsiniz. Bu sistem, her hatayı bir trajedi, bir destan, bir milli yas haline getirir.

## Nasıl Çalışır?
`hata_ureticisi.py` dosyasını çalıştırın. Rastgele bir abartılı hata mesajı üretir. Gerçekten çalışır. Deneyin. Ağlamayın.

## Özellikler
- %100 çalışan kod
- Hiçbir işe yaramaz
- Ama çok ciddi

## Kullanım
```bash
python hata_ureticisi.py
```
